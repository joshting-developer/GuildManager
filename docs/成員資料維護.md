# 成員資料維護

2026/10/19 新功能補充，僅供 admin／manager。member 的既有新增、編輯、移至編外與匯入仍可使用。v1.0.11 已同步 GAS 程式，仍需更新 Web App 部署版本才會對外生效；本次未更新部署。

## 修正 UID

1. 在「成員清單」找到正確的人，按「編輯」。
2. 開啟「開啟 UID 修正」，原本鎖定的 UID 欄位即可輸入。
3. 核對遊戲內 ID，保留前導零，按「儲存」。不能改成名冊已使用的 UID。

原本的報名／請假、舊名、戰績及排表關聯會接到修正後的 UID，現在名稱、職業與所屬狀態可一起修改。關閉開關會還原原 UID。

## 新增、修正與刪除舊名

1. 點該列「過去名稱」紀錄；沒有紀錄時會顯示「新增舊名」。
2. 用「新增過去名稱」補上舊名，或直接修正欄位。垃圾桶只先從草稿移除。
3. 按「儲存過去名稱」。現在名稱保持不變，不需要先把角色改回舊名。

新增或修正舊名不可與現在名或其他舊名重複；既有改名歷史若重複，可保留原紀錄。新增時間只是這次補資料的時間，不代表實際改名日期。

舊名儲存後**不會立即重新分配戰績**。需要歸納舊名戰績時，由 admin 到「帳號管理 → 資料維護 → 同步歷史戰績」，先檢查預覽再確認；同名衝突會跳過，已歸屬其他人的資料不會自動轉移。

## 永久刪除錯誤資料

1. 在該列按紅色「永久刪除」。成員與編外人員都可操作。
2. 核對姓名與 UID，輸入完整 UID。
3. 按「確認永久刪除」，等候成功提示。想取消則按「保留成員」。

將移除成員、全部過去名稱、本場報名／請假及個人戰績關聯。**原始戰績 CSV、玩家數值與排表當時的姓名仍保留**；不會因此刪掉整場比賽或排表。這個操作沒有復原按鈕。

只是退出幫會／俱樂部時，仍建議使用「移至編外」，可保留資料與關聯，之後編輯所屬狀態即可回歸。GAS 的歷史提交列與備份仍保留，永久刪除不是清除所有歷史檔案。

儲存失敗會保留輸入；若提示資料已更新，請關閉視窗、重新載入成員清單後再操作。請勿同時在其他分頁修改同一人。
