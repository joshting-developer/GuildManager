# 行事曆影片連結與閱覽（本機）

## 需求與假設

- 行事曆戰鬥視窗新增「影片上傳」tab，第一場／第二場各自保存名稱、網址與團別。
- 團別固定為進攻一、進攻二、防守團；三種戰鬥都提供兩場，與戰績 CSV 場序限制分開。
- 只保存連結，不接收影片檔案；每場可有多位玩家提交，不要求名稱有名冊 UID。
- 送出沿用原行事曆權限：約戰可公開提交，幫戰／龍虎戰需登入；登入者寫入需 CSRF。
- 新增登入後的影片閱覽頁，僅 admin、manager 可選場次查看兩場影片；依使用者補充，member 不可讀取清單，仍可提交影片。
- 本次只實作本機 SQLite／HTTP；GAS 不提供入口，不同步至雲端。

## 步驟

1. 建立影片驗證、SQLite 資料表、API 與權限；驗證場次限制、連結格式、重試及保存。
2. 加入行事曆表單與影片閱覽、桌面／手機畫面與未送出保護；更新文件。
3. 完整測試、兩種編譯、本機實際 API 瀏覽器驗證；各步驟提交並保留本機預覽。

## 驗證

- 隔離 SQLite：場次／場序分離、重啟保存、相同提交重試、相同 requestId 衝突、過期／已刪／一般活動拒絕。
- API：匿名約戰提交、私有場次登入、admin／manager 閱覽與 member 清單拒絕、CSRF 與 member 管理拒絕。
- UI：兩場草稿、切換報名分頁保留、成功清除本場、失敗保留、重新載入、外連及手機無橫向溢出。
- 不播種日常資料庫或修改正式試算表；本機現有 Docker 為使用者預覽環境。
