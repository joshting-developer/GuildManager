# 團隊戰績分析

## 需求與假設

- 對戰詳情提供「團隊分析」彈窗，member／manager／admin 可讀，不放寬排表管理權限。
- 暫以進攻團三隊 → 進攻1、機動團三隊 → 進攻2、防守1／2隊 → 防守12隊、防守3／4隊 → 防守34隊；分團確認已詢問，等待回覆。
- 使用者已確認全場比例以同陣營全部 CSV 玩家為分母，包含未歸類者；紅藍分開分析，內推同樣不混用分母。
- 第一場使用第一人，第二場有第二人時取第二人，否則沿用第一人；舊未指定場序不猜測。
- 讀取活動最後儲存的排表，標示儲存時間；目前戰績沒有固定排表版本引用，因此之後重新保存排表會影響分析。不使用未保存草稿，不改歷史資料。
- 最後排表日期／類型與戰績不符時不分團，避免活動改期後誤用新排表。
- 優先以戰績既有成員關聯與排表 UID 比對；沒有 UID 關聯才用排表快照姓名精確比對。跨陣營重複姓名、UID 或多個排表人選不猜測，歸未分類。已關聯他人不以姓名轉移。
- 四團只包含實際 CSV 玩家。未分類獨立分頁，不算團內合計但保留於本陣營全場分母。
- 進攻指標：塔傷、承傷、人傷、擊殺、助攻、重傷、治療、化羽／清泉；防守指標：人傷、擊殺、助攻、資源、重傷、治療、化羽／清泉。
- 各格顯示數值、團內％、全場％。分母為 0 或缺值時比例顯示 —；缺值保留，不當作 0，部分合計標示。

## 步驟

1. 共用純分析函式、本機／GAS 唯讀端點及 adapter；驗證分團、分場、身分、缺值、比例與權限。
2. 對戰詳情按鈕、共用彈窗、紅藍切換與團別表格；驗證載入、錯誤重試、過期回應、手機及鍵盤。
3. 更新規範與操作手冊（附示範截圖），產生 HTML／PDF，檢查差異及本機提交。
