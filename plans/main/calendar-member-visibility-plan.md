# 行事曆登入與戰鬥可見性

使用者確認所有共用登入視窗預設成員通行密碼；活動與約戰維持公開，幫戰與龍虎戰須有效 member／manager／admin 登入才能看到。首頁登入完成後留在行事曆；管理及分析直接連結沿用原目標與權限。移除報名視窗內的登入表單，統一右上入口。

實作：後端過濾公開活動 API；前端即時過濾、登入／登出重新載入、過期或撤銷清理私人場次視窗，忽略舊請求回應；更新文件及驗證後獨立提交。沿用暫停的 GAS 草稿，不恢復整體 GAS 工作或正式試算表寫入。

驗證：匿名只收到活動／約戰，三角色看到全部，撤銷／過期恢復公開清單；原參與端點仍保護。隔離瀏覽器確認登入預設、日曆內容與筆數、報名直達表單、移除內嵌登入、登出／撤銷、慢請求與手機／鍵盤。本機測試與本機／GAS 編譯。

結果：`npm test` 156 項通過（包含暫停中的 GAS 草稿 3 項）；`npm run build`、`npm run build:gas` 通過。隔離記憶體 SQLite／Chrome 完成匿名與三角色、匿名約戰報名、登入後直接報名、登入後留在首頁、登出與撤銷關閉視窗、登出後舊請求不回填、重新整理保留登入、320／390／768／1440px 及鍵盤操作驗證。未使用日常資料庫，未寫入正式試算表，未部署或驗證 Google 執行環境。GAS 草稿保留未提交狀態。
