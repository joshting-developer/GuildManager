# 成員匯入計畫

## 需求與假設

- 成員清單新增匯入, 欄位順序 UID、Name、主職業、副職業
- 使用者確認 Job1／Job2 只是欄位代稱, 值依目前主／副職業名稱
- 支援貼上文字與 UTF-8 CSV／TSV／TXT, 可以有表頭, 表頭接受 UID Name 主職業 副職業及原始 Job1 Job2
- 副職業填 `-`、`無副職業` 或 TSV／CSV 空欄, 主職業需存在於職業表
- UID 保存為文字, 不轉成數字；四欄必須完整, 空白分隔名稱不得含空白, 含空白可用 Tab 或 CSV 引號
- 使用者確認重複已在會 UID 跳過、不覆寫, 新增成功後用彈窗提醒實際新增／跳過筆數
- 匯入內部重複 UID 或任何無效列需修正後才能送出, 不偷偷只匯入部分列
- 預覽不寫入, 確認時重新驗證且檢查預覽版本, 寫入使用同一交易
- 同 UID 退會後再匯入沿用加入規則, 恢復並保存過去名稱
- 每批最多 500 位、文字／檔案最多 256 KiB, 不支援 Excel 二進位檔

## 步驟

1. 完成解析、預覽／匯入 API、資料交易與測試後提交
2. 完成匯入表單與檔案操作、adapter、文件, 瀏覽器／Docker／build 驗證後提交

## 驗證

- CSV／TSV／空白、表頭、BOM／CRLF、名稱含空白、前導零／長 UID
- 不存在職業、欄位數不符、匯入內重複 UID、既有 UID、退會成員恢復
- 預覽後資料變動拒絕匯入, 後續寫入失敗整批回滾
- 修改輸入後重新預覽, 讀取／儲存錯誤保留內容, 重複提交鎖定
- 桌面／手機、鍵盤、焦點返回, 隔離 SQLite 不留下測試成員
- 一般與 GAS build, GAS 匯入仍明確回報未串接
