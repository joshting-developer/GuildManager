# API 等待狀態

- 公開與管理月曆在登入確認及安排 API 完成前顯示中央載入遮罩，不將空月曆呈現為已完成；更新時保留月份且停用資料操作，失敗提供重試。
- 共用轉圈與載入文字，涵蓋既有清單、戰績、設定及出勤／報名／對戰編輯視窗；減少動畫設定下保留靜態圖示與文字。
- 戰績上傳新增場次選單載入狀態，資料讀取前不能選／上傳且不顯示空場次提示；影片場次、個人職業及排表來源更新有明確進度與停用狀態。
- 以延遲的模擬 GAS RPC 驗證等待、成功、空資料、失敗及重試，檢查登入確認、桌面／手機排版、切換頁面及過期回應；執行兩種編譯及既有測試。
- 本次不同步 GAS、不改正式資料與權限，不加入人為延遲；更新規範及驗證紀錄後本機提交。

- 使用者追加送出流程：表單及寫入附近持續顯示轉圈與明確文字，配合既有停用／persistent／防重複狀態；不使用全頁寫入遮罩，保留草稿與使用情境。
