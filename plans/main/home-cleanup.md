# 總覽入口與行事曆調整

## 需求與決策

- 使用者要求移除重複區塊, 最終確認保留上方一排管理入口, 移除下方一排
- 上方集中成員清單、活動安排、出勤紀錄、幫戰資料, 成員清單可進入, 其餘待開發
- 頂部導覽保留以便跨頁切換, 首頁內容只有一個成員入口
- 取消幫會公告功能, 訊息主要在 Discord 處理, 不新增 Discord 串接
- 移除公告畫面、文案、樣式與未使用的首頁公告資料契約
- 不刪除既有 SQLite 資料, 新資料庫不再建立公告表
- 近期活動改為月曆, 支援上／下個月、返回今天, 依台北日期標示今天
- 約戰安排將在後續接入, 目前只顯示真實日期與尚未串接狀態, 不放假活動

## 步驟與驗證

1. 實作入口精簡、公告移除與月曆, 同步資料介面及文件
2. 執行既有測試、一般及 GAS 編譯, 瀏覽器確認桌面／手機、跨年／閏月日期與鍵盤操作
3. 檢查差異後提交本步驟

## 結果

- `npm test`：20 項通過, 公告欄位移除後首頁／成員資料介面仍正常
- `npm run build` 與 `npm run build:gas` 成功, GAS 單檔約 673 KB
- Chrome 桌面 1440px、手機 390px：只顯示上方四個管理區塊, 公告與下方重複區塊已移除
- 成員入口能進入 `#/members`, 沒有增加假統計或假約戰
- 月曆顯示正確的 42 個日期, 上／下個月、返回今天與鍵盤 Enter 可操作
- 驗證 2025 年 12 月跨至 2026 年 1 月, 2028 年 2 月含 29 日
- 美國時區瀏覽器仍以台北日期標示今天, 桌面與手機無整頁橫向溢出
- Docker 原始碼熱更新已驗證, 最後重建映像同步新的測試與文件
- 未寫入或刪除既有資料, 約戰資料與 GAS 實際部署仍待後續串接
