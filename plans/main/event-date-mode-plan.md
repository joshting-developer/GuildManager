# 日期選擇模式與登入進度

## 需求與假設

- 安排日期新增「行事曆模式／日期選單模式」，預設行事曆；日期選單以起訖日選取完整期間，包含兩端。
- 兩種模式共用日期陣列，切換本身不填補不連續日期。活動、建立幫戰／龍虎戰可多日；約戰與編輯幫戰／龍虎戰只能一天，最多 366 天。
- 無效或未完成的日期區間阻止儲存，不以先前有效日期偷偷送出；失敗保留輸入。
- 登入只保留送出按鈕的轉圈，附近文字提供可讀取的等待狀態。
- 本次修改本機來源及 GAS 編譯產物，不上傳正式 Google 專案或寫入正式資料。

## 步驟與驗證

1. 日期區間 helper、共用安排視窗、登入進度調整；測試包含閏年、跨月、日期邊界、單日及 366 天限制。
2. Chrome／Playwright 隔離 GAS 模擬確認模式切換、批次及編輯規則、無效輸入與失敗保留、桌面／手機及登入單一進度；編譯一般與 GAS 版本。
3. 更新操作文件與截圖、檢查差異並分步提交。

## 結果

- `npm test`：219 項通過，包含 3 項新增日期區間驗證；一般及 GAS 編譯成功，GAS HTML 保持單檔。
- Chrome／Playwright 使用隔離 GAS runtime：成員／管理者登入各只有一個進度圖示，等待期間禁止分頁／關閉；整月 31 天、模式切換不填補不連續日期、行事曆與區間互通、手機單欄及無頁面溢出通過。
- 反向、未完成及超過 366 天區間不發送儲存；失敗保留草稿及 requestId；約戰單日、龍虎戰三日期建立三筆獨立場次、編輯單場僅一天通過。
- 手冊更新日期模式說明及兩張截圖，新增圖片僅使用示範資料；離線 HTML／PDF 驗證另記於文件步驟。
- 未上傳 GAS、更新部署或操作正式 Google 試算表；真實 Google API 行為仍須部署後確認。
