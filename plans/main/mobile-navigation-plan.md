# 手機右側導覽選單

## 需求與範圍

- 1100px 以下使用固定於上方的精簡頂欄，登入後只有品牌與選單按鈕；未登入保留登入。
- 選單從右側滑出，寬約手機畫面的 80%，遮罩保留背景頁面，登出放底部。
- 沿用現有角色入口與路由防護，桌面導覽不變，不同步正式 GAS。
- 關閉、背景與 Escape 可收起，保留捲動及輸入；鍵盤焦點留在選單，收起返回入口，換頁移至主要內容。

## 步驟與驗證

1. 使用 Vuetify modal 實作側邊選單、精簡頂欄、焦點與桌面切換處理。
2. 編譯一般及 GAS 版本，使用隔離 GAS 模擬與瀏覽器確認角色入口、手機／桌面、捲動、焦點、換頁及登出。
3. 更新相關規範與手冊手機圖片，完成驗證後按步驟提交。

## 驗證結果

- `npm test`：208 項通過；HTTP 測試在允許本機監聽的環境執行，使用隔離資料。
- `npm run build`、`npm run build:gas`：通過，GAS 單檔約 989 KB，沒有新增依賴。
- Chrome／編譯後 GAS 前端搭配隔離模擬後端：確認匿名、member、manager、admin 入口；390px 抽屜寬 312px、頂欄 56px；開啟不推動背景、鎖定捲動、關閉還原位置與搜尋輸入；Tab／Shift+Tab、Escape、遮罩、關閉按鈕及焦點返回正常。
- 切換頁面收起並聚焦主要內容，切回 1440px 恢復桌面導覽；390×360 短畫面清單獨立捲動且登出保持可用；登出失敗留在抽屜內並可重試。
- 從已捲動的成員頁切換戰績閱覽後，確認新頁回頂端並聚焦主要內容；點同一入口保留原篩選。
- 手機圖片與第 6 版手冊已更新，HTML／PDF 重新輸出；18 章＋目錄、33 張圖片、所有章節連結、離線圖片放大／Escape、手機排版及含標籤／書籤 PDF 驗證通過。
