# 平台圖示與副職業篩選

## 需求與假設

- admin 平台設定可選擇、預覽、替換與移除圖示；儲存成功後更新頂欄，無圖示不留占位。
- PNG／JPEG／WebP，單檔最多 256 KB。圖片只作品牌顯示，不接受 SVG 或任意外部 URL。
- 本機 SQLite 保存圖片；GAS 私人 Drive 保存原檔、GM_settings 保存引用，公開設定只回傳當前圖示的 data URL，不洩漏 Drive ID。不需 R2。
- 名稱與圖示同次保存，保留 revision／CSRF／admin 權限與相同成功請求重試。失敗保留草稿；跨 Drive／Sheets 失敗可能留下未引用私檔，不自動刪除。
- 成員與編外分頁加入副職業與無副職業篩選，所有條件取交集，清除及分頁重設沿用既有操作。

## 步驟與驗證

1. 完成圖示前後端及文件；隔離 SQLite／GAS 測試驗證權限、格式、版本、重試、移除與保存，實際瀏覽器確認預覽／保存／手機版，再 commit。
2. 完成副職業篩選；瀏覽器驗證交集、無副職業、清除、分頁與編外，檢查手機版，再 commit。
3. 執行完整測試與兩種編譯；沿用已授權 clasp 程式同步、遠端備份及讀回比對。不上線發布、不初始化正式試算表。

## 驗證紀錄

- 圖示：平台名稱與圖示相關測試 7/7 通過；隔離 GAS 瀏覽器確認 PNG／JPEG／WebP、預覽不提前修改頂欄、未儲存離開提醒、儲存失敗保留、改名不清圖、重新整理、移除／還原、SVG 拒絕與 390px 手機無橫向溢出。GAS 單檔編譯通過。
