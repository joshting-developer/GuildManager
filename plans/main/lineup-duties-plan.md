# 排表職責清單

## 原始需求與理解

使用者希望將圖片中的保鑣、山盟、輔潮等職責保存成資料表, 提供職責分配清單並可拖曳至排表。

- 工作目錄乾淨, 沿用 main；這是新增功能, 不需重現既有錯誤。
- 假設每個位置可有多項職責, 同一職責可用於多人；職責屬於位置, 成員移動不搬移職責, 與既有備註一致。
- 初次建立清單只加入使用者明列的保鑣／山盟／輔潮；可新增、改名、停用／啟用, 以固定 ID 關聯。
- 空位也可先規劃職責, 位置視窗提供多選／移除, 手機與鍵盤提供點選替代拖曳。
- 範本保存 dutyIds, 確認快照由後端取得當時職責名稱；後續改名／停用不改歷史。
- 套用範本跳過已停用職責並提示位置／原因, 既有自由文字備註與舊版快照完整保留。
- 缺少 dutyIds 的舊排表視為空陣列；舊 requestId 的重試仍需取得原結果, 不重寫不可變資料。
- 本次範圍為本機 API／SQLite 與介面, GAS 只追加明確未串接的函式及 adapter。
