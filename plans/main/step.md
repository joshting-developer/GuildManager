- 瀏覽器驗證活動篩選、詳情、空白預覽、手機選單、鍵盤焦點返回與 API 失敗／重試
- 1440px 桌面與 1024／768／390／320px 版面無橫向溢出, 無 page error
- 桌面與手機截圖保存在 `artifacts/`, 不加入 Git

- 實際單檔 HTML 約 520 KB, 以模擬 GAS bridge 渲染成功, 沒有 HTTP 或外部資源請求；缺少 bridge 時顯示錯誤, 不回退至假資料
