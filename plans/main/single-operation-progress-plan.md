# 統一單次操作的進度提示

## 需求與規則

- 整理同一次儲存／送出同時出現兩個轉圈的介面，保留操作按鈕的轉圈與附近狀態文字。
- 共用 DataLoading 增加可關閉圖示的選項；role=status、aria-live 與原文案維持，預設讀取流程仍顯示圖示。
- 覆蓋帳號／平台設定、成員與匯入、活動、報名／影片、取消請假、排表／範本／職責、戰績上傳／編輯與歷史同步。
- 混合狀態逐一判斷：檔案讀取、重新載入或套用範本沒有按鈕進度時仍保留共用圖示。
- 不修改資料 API、權限、重試／版本保護；失敗保留草稿，處理中停用重複操作。本次不自動同步 GAS。

## 步驟與驗證

1. 逐一檢查 DataLoading 與按鈕的狀態來源，調整共用圖示及對應使用點。
2. 編譯一般／GAS；用 Chrome／Playwright 與隔離 GAS 延遲回應檢查可見轉圈數、狀態文字、成功／失敗、停用及手機版。
3. 更新介面規範與驗證結果，明確暫存相關檔案並提交。

## 結果

- 13 個介面／視窗的 18 處共用進度改為純文字或依狀態切換圖示；DataLoading 預設讀取轉圈不變。取消請假期間停用出勤分頁，避免切走後隱藏正在處理的按鈕。
- `npm test`：219／219 通過；`npm run build` 與 `npm run build:gas` 成功，GAS 前端仍為單檔，沒有新增套件或修改後端契約。
- Chrome／Playwright 與隔離 GAS 延遲回應：帳號／平台／通行密碼、manager 建立與修改、歷史同步、成員新增／修改／移至編外、匯入預覽／確認、活動建立／修改／刪除、取消請假、報名／請假、影片、一般／專注排表、範本、代為報名、職責、來源更新、戰績上傳與資訊編輯，每次顯示一個可見轉圈及 role=status／aria-live 文字。
- 成員儲存與戰績上傳的失敗、重試及成功通過；手機 390px 沒有頁面溢出，成員表單等待時禁止重複操作／Escape 關閉且失敗保留輸入。減少動畫狀態下仍能看見進度。
- 檔案讀取與套用範本沒有按鈕轉圈，確認仍保留一個區塊轉圈；等待未被移除。既有手冊截圖皆為非等待畫面，本次操作步驟不變，未重製手冊。
- 驗證使用隔離模擬，未操作正式 Google 資料或同步 GAS；GASDeployment.md 已標示上次同步來源 b62c9fd 與本次待同步狀態。
