# 管理端場次出勤閱覽

- 管理總覽當日安排視窗與活動安排清單，約戰／幫戰／龍虎戰各增加「出勤閱覽」；一般活動沒有報名資料，不顯示入口。
- 共用視窗預設請假；約戰有請假／報名兩個分頁且含實際人數，幫戰／龍虎戰隱藏報名分頁；名稱、當場職業與備註完整顯示，不顯示 UID。
- 計數只包含實際請假或報名的名冊回應及本場外援；未回應／舊 none 不算報名，已取消外援歸請假；不同場次不混用。
- 新增本機及 GAS 管理專用讀取及取消請假契約，沿用現有 participation 資料來源，不新增資料表；admin／manager 可用，member／匿名拒絕，寫入檢查 CSRF。
- 管理取消名冊成員請假改回 none（解除請假但不新增報名），所屬身分不變；額外報名者的請假代表取消報名，撤銷請假恢復原報名及原 ID。均保留備註、檢查 revision，同一成功操作可安全重試，資料已更新需重新載入。
- 每次開啟重新讀取，支援載入、空名單、失敗重試及手動重新載入；未知人數不用 0 代替，關閉／換場避免過期回應；鍵盤／手機可用並恢復入口焦點。
- 驗證來源、計數、狀態切換與角色限制，執行完整測試與本機／GAS 建置，瀏覽器檢查兩入口及各狀態。
- 更新規範及附圖操作手冊，再依步驟提交。本次不自動同步 GAS 或修改正式資料。
