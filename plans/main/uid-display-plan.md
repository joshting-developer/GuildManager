# 玩家 UID 顯示範圍

## 需求與現況

使用者要求：「玩家的UID感覺只有成員清單 那個管理介面顯示就好了 其他地方不要顯示」

- 工作目錄乾淨, 分支 main
- UID 目前出現在公開報名選單、排表來源／位置選單、位置 title、範本跳過提示及部分錯誤／缺失資料回退
- 僅成員管理頁及其新增／編輯／匯入／過去名稱／移至編外視窗保留 UID
- 其他頁面只顯示名稱與必要的職業、額外報名標記；缺資料時顯示找不到成員, 不回退顯示 UID
- UID 繼續作為內部關聯、選項值、唯一性與快照引用, 不改資料表或既有歷史
- 本次為顯示規則調整, 不新增身分綁定、遮蔽 API 欄位或同名管理功能
