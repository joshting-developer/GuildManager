# 活動安排修改與刪除

## 需求與假設

- 活動安排清單提供修改、刪除, 修改名稱、類型及日期。
- 沿用活動 1–366 天、約戰一天與台北日期規則, 編輯預填既有資料。
- 刪除確認列出名稱及影響日期筆數, 成功後才移出畫面；取消不寫入。
- 以 revision 防止舊畫面覆寫／刪除新版本, 失敗保留表單並提示重新載入。
- SQLite 保留刪除標記以避免延遲的建立重試重建已刪安排, 查詢與月曆不顯示已刪資料。
- 本次不加入報名、出勤或登入；GAS 新函式保留未串接回應。

## 步驟與提交

1. 資料欄位相容遷移、修改／刪除交易、HTTP／GAS adapter, 驗證後提交。
2. 共用編輯表單、清單操作與刪除確認、錯誤及焦點處理, 更新文件並驗證後提交。

## 驗證

- 隔離 SQLite 驗證既有資料遷移、修改單日／多日、無效資料、版本衝突、重試、刪除日期排除、交易回滾及重啟保存。
- API 與本機／GAS adapter 驗證 ID／revision 傳遞及失敗處理。
- 瀏覽器驗證編輯預填、類型切換、成功更新、刪除確認／取消／失敗／成功、首頁月曆、手機及鍵盤焦點。
- 既有測試、一般／GAS build, Docker 健康檢查。
- 寫入測試只使用暫存資料庫, 不修改日常資料或正式試算表。
