# 排表改為直接編輯與儲存

## 需求與現況

使用者：「感覺工作區機制太麻煩了 反正真的要過去的就把以前的存成範本就好了」

目前排表保存後切換為歷史唯讀, 需再載入工作區才能修改, 另有工作區／歷史版本選單及二次儲存確認。使用者希望每場直接編輯目前排表, 想保留配置時手動另存範本

## 決定與範圍

- 每場載入最後一次儲存的排表, 沒有排表時顯示空位；直接編輯並按「儲存排表」, 儲存後可繼續修改
- 移除「瀏覽排表」選單、載入工作區及儲存確認視窗, 顯示「尚未儲存／有未儲存修改／已儲存」狀態
- 範本沿用另存及套用功能, 套用後可調整再儲存；套用／切換場次／離開前保留未儲存提醒, 沒有自動儲存
- 排表來源、主／副職業、雙場、職責、約戰安排後隱藏來源及 UID 顯示規則不變
- 不搬移、刪除或自動轉換既有資料；後端版本與快照保留作相容及多人修改／重試檢查, 不在日常操作暴露版本機制
- 被刪除或改為一般活動的場次, 最後保存的排表仍可唯讀查看與另存範本, 不可儲存或套用範本至原場次
- 範本仍保存人員 ID 與配置, 套用時按現有資料及資格檢查；不新增歷史版本管理或自動快照範本介面
