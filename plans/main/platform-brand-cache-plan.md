# 幫會名稱與圖示快取

## 需求與假設

- 再次進入先顯示上次成功的名稱與圖示，讀取最新設定後更新；成功儲存同步快取，失敗不覆寫。
- 瀏覽器 localStorage 只存公開品牌資料，依本機來源／GAS 指令碼隔離；不存憑證或草稿。
- GAS doGet 已讀取設定，直接注入這份公開資料供首次呈現，避免重複 RPC；安全處理 script 文字。
- 無有效快取或初始資料時顯示占位，不先顯示預設「逆水寒」。儲存空間受限或資料毀損時仍能正常讀取與儲存後端設定。
- 不同步正式 GAS，不改權限或資料表。

## 步驟與驗證

1. 實作品牌快取、GAS 初始資料及首次載入占位，保留既有過期回應保護。
2. 驗證快取隔離、資料檢查、儲存失敗／空間受限、初始資料 script 轉義；執行相關測試及兩種編譯。
3. 使用編譯後前端及隔離 GAS 模擬驗證冷／暖啟動、慢速／失敗讀取、成功儲存與圖示移除，檢查桌面與手機並提交。

## 結果

- `npm test`：212 項全部通過；包含新增的快取隔離、毀損／尺寸／格式檢查、儲存空間受限與 GAS 初始資料轉義測試。
- `npm run build`、`npm run build:gas`：通過，GAS 前端單檔約 990 KB，無新增套件或外部檔案依賴。
- Chrome／編譯後 GAS 前端搭配隔離模擬：無資料顯示占位、暖啟動立即顯示名稱／圖示，慢速回應前保留快取、收到新設定更新名稱並移除圖示；讀取失敗保留快取且可重試，儲存失敗不更新品牌，成功儲存後重新整理維持新品牌。
- GAS doGet 公開初始資料立即呈現，首頁不重複呼叫品牌 RPC；script 結束標籤與 $& 等名稱字串保持文字，不插入額外標籤或憑證。手機 390×844 無橫向溢出，已視覺檢查。
- 未同步正式 GAS；真實 Google 服務及 iframe 瀏覽器儲存行為未實測，儲存不可用時仍可使用伺服器初始資料。
