# member 開放完整成員清單操作

- member 登入後顯示成員清單導覽，支援直接連結／重新整理／手機入口；成員／編外分類、UID、歷史、篩選、查看數據及所有既有操作與 admin／manager 相同。
- 開放成員清單讀取、新增、修改、移至編外、匯入預覽／確認；本機只放行對應 HTTP 路徑／方法，GAS 只放行對應業務 RPC。仍須有效登入及原有 CSRF、輸入驗證、revision／匯入版本檢查。
- 其他管理總覽、活動、排表、戰績寫入、影片閱覽、出勤閱覽、帳號／平台設定沿用原權限，不將 member 全域改成管理角色。
- 以隔離 SQLite／HTTP 及模擬 GAS 測試 member 的完整成員流程、匿名拒絕、CSRF、版本衝突、session 撤銷與其他管理功能限制；完整測試、兩種編譯及桌面／手機操作驗證後提交。
- 更新權限規範及操作手冊，本次不自動同步 GAS。


## 驗證結果

- `npm run build`、`npm run build:gas` 通過，GAS 單檔編譯成功。
