# 同位置第一場／第二場

## 原始需求與理解

「把兩個人滑到同一個位置上的時候，會把那一列名字的地方變成第一場／第二場」。現況拖入占用位置會交換，無法保存兩位成員。工作目錄乾淨，沿用 main。

- 同位置最多兩位，第一位第一場、第二位第二場；未指定第二場時沿用第一位。拖入第三位提示先編輯，不覆寫。
- 成員 UID 在整份配置仍唯一，移動會清除來源的該場分配；同位置重拖同 UID 不新增。點選亦可分場，位置編輯可指定／移除兩場人員及各自上場職業。
- 職責與備註仍屬於位置、兩場共用。不新增第三場、報名或不同日期的排表。
- 保留 slot.uid／profession 作第一位，新增可空 secondRound {uid, profession}；確認快照亦保存第二位當時姓名／職業，範本逐人檢查資格。
- 舊 JSON 缺 secondRound 以 null 正規化，讀取不重寫不可變快照，重試舊 requestId 保留原結果；不搬移資料表或寫正式試算表。
- 總人數與位置數分開，避免超過 60 人時空位計算負數。未分場的成員兩場沿用；分場格明確顯示標籤，沿用緊湊版面。
