# 團隊分析合計與個人明細分表

## 需求與假設

- 團別分頁內先顯示「本團合計」表，保留各項合計並新增本團占全場的比例；下方保留個人明細，移除原表尾合計。
- 全場沿用已確認的同陣營全部玩家（含未歸類）作分母，紅／藍切換仍可分析各自陣營，不從隊名推估我方。
- 部分本團資料、分母缺值或合計為 0 時，比例顯示 —；合計依整團而非個人分頁計算。
- 未歸類仍只顯示既有姓名／職業／原因表，不新增無意義的團合計。
- 使用者追加個人明細排序：角色名稱／職業／數值點表頭切升降，未歸類原因亦可排序；數值比較原始值，缺值雙向置尾，排序在分頁前完成，不更動合計。合計兩列保留固定順序。

## 步驟與驗證

1. 共用分析函式補團合計的全場比例，前端分成合計／個人兩表；更新開發及風格規則。
2. 以既有分析測試補正常比例、部分資料、零值與兩陣營契約檢查，執行測試及一般／GAS 編譯。
3. Playwright 使用本機示範資料隔離副本驗證兩表、團別切換、明細無表尾及手機容器捲動；不修改日常資料或同步 GAS。
4. 檢查差異並提交此次相關檔案。

## 結果

- 已完成獨立本團合計表：合計與占同陣營全場％兩列；個人明細不再顯示表尾合計。
- 共用分析函式提供各團合計的 wholePercent，本團或分母部分資料時回傳 null，完整已知的 0 值仍可顯示 0％；沿用本機／GAS 相同契約。
- 明細採既有數值排序函式，點名稱／職業／指標表頭切升降，未歸類亦可排序原因；原始數值比較、缺值置尾、分頁前排序，不更動來源或合計。
- `npm test`：226／226 通過，包括新團合計比例測試與 SQLite／GAS 回應一致性。首次沙箱執行禁止 localhost 監聽，改允許隔離本機測試埠後全數通過。
- `npm run build` 及 `npm run build:gas` 通過；GAS Index.html 約 1016.7 KB，確認沒有外部 JS／CSS 檔案標籤。一般版保留既有 bundle 大於 500 kB 提示。
- Playwright 操作實際 Vite 前端與隔離資料副本，確認四團兩表、合計及全場比例、明細無表尾、數值雙向／名稱／職業排序、鍵盤操作、切藍方未歸類單表、排序回第一頁及防守資源欄。
- 390px 手機驗證兩表獨立橫向捲動、頁面不溢出及底部關閉可使用；桌面及手機截圖留在忽略的本機資料備份目錄，不提交真實玩家姓名圖片。日常資料與帳號 session 未修改。
- 未同步 GAS 或更新部署。
