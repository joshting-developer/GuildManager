# 圖文操作手冊

- 依目前已實作功能製作繁體中文圖文手冊，區分訪客／member／manager／admin 可用操作。
- 先確認既有測試圖片；使用最新版 GAS 單檔 HTML 與隔離模擬 Google RPC 補拍一致畫面，不讀取正式資料、憑證或私人帳號檔。
- 涵蓋登入與行事曆、報名／請假、職業統計、影片提交與閱覽／匯出、成員與匯入、活動、排表與範本／JPG、戰績上傳／閱覽／個人統計、admin 設定。
- 提供 Markdown 來源、離線 HTML 與可分享的 PDF；圖片使用明確示範角色與場次，截圖日期和數字只作範例。
- 驗證操作文案／權限與原始碼一致、所有圖片／章節連結存在、網頁與 PDF 可閱讀，再依專案規則 commit。
- 只交付文件及圖片，不修改應用功能、不同步 GAS 或更新部署。

## 完成與驗證

- 操作手冊包含 18 章及 26 張最新版截圖；依角色列出功能權限，逐步說明日常操作及常見問題。
- Markdown 作來源；Python 標準函式庫產生單檔離線 HTML，圖片內嵌且可放大；Chrome 產生 A4 PDF，含書籤、目錄連結及頁碼。
- 全部 PNG、Markdown 圖片／章節連結、HTML 18 章／目錄與 26 張圖片載入通過；無外部資源或瀏覽器錯誤，圖片放大／Esc 關閉、390px 手機版及 PDF 產生已驗證。
- 截圖採隔離模擬 Google RPC 與示範資料，沒有讀取憑證、私人帳號檔或正式 Google 資料。正式雲端的既有驗證限制不變。
- 文案對照目前 Vue 畫面及權限；只改文件，不執行 npm test／應用編譯或 GAS 上傳。
