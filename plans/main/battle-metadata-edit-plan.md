# 已上傳戰績的對戰資訊編輯

- 已上傳卡片及對戰詳情提供管理者「編輯對戰資訊」；admin／manager 可修改雙方名稱、我方、勝方，約戰可逐場切換內推。member 只可閱讀。
- 內推只限約戰，保存時清除我方／勝方，第一場與第二場互不影響。未填勝方仍顯示結果未填，切回一般對戰可另選結果。
- CSV、玩家快照、關聯、日期／類型／場序／活動與原上傳重試資料不變；個人分析及各閱讀頁使用最新結果。
- 本機追加戰績 revision 及編輯重試記錄；GAS 舊資料讀取 revision 預設 0，沿用 script lock／提交標記。管理 API／RPC 驗證角色、CSRF、revision、requestId、白名單欄位與有效值。
- 共用編輯視窗每次開啟讀取最新資訊，載入／錯誤／重試、欄位驗證與未儲存離開提醒；衝突不覆蓋輸入，儲存成功才更新卡片／詳情，關閉恢復焦點。
- 隔離 SQLite 與模擬 GAS 驗證保存、並行、重試、原資料不變與權限；完整測試、本機／GAS 編譯及桌面／手機／鍵盤瀏覽器驗證後提交。更新使用文件。本次不自動同步 GAS。
