# 幫戰／龍虎戰名稱選填

## 需求、現況與範圍

使用者：「龍虎戰跟幫戰活動名稱可以免填留空，看會不會出問題，因為實際使用上很難知道幫戰跟龍虎戰對手是誰」。開始工作目錄乾淨, 沿用 main。

- 幫戰／龍虎戰建立 (含多日批次) 與編輯可留空／清空名稱；空白字元正規化為空字串, 可省略 title。活動／約戰名稱仍必填。
- SQLite title TEXT NOT NULL 可保存空字串, 目前無非空 CHECK, 不需改表、搬移或覆寫既有紀錄。保存實際空字串, 不產生虛構對手或正式預設名稱。
- 限制 120 字、文字格式及原日期／revision／requestId 規則保留；改成需要名稱的類型時仍檢查必填。
- 頁面名稱回退為類型文字, 搭配現有日期辨識；月曆／活動清單／詳情／成功訊息／刪除確認與 aria-label／排表選單／確認／歷史都檢查。
- 共用 eventDisplayTitle 只用於顯示, 表單仍載入真正空值。未命名操作按鈕加入日期, 排表選單以日期及類型顯示。
