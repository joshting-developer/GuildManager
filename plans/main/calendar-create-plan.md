# 行事曆日期建立安排

## 需求與假設

- 首頁行事曆點擊日期格即可開啟建立安排視窗, 預選點擊日期。
- 日期格包含目前月份以外的日期, 開啟表單時顯示該日期月份。
- 沿用活動多天、約戰一天的規則與現有 API, 不新增資料欄位。
- 已有安排的日期仍可點擊安排名稱／筆數查看詳情, 其餘格子範圍可建立安排。
- 成功後即時更新首頁月曆, 保留瀏覽月份；錯誤保留表單輸入。

## 步驟

1. 共用建立表單, 加入行事曆日期入口、焦點返回與成功提示。
2. 驗證首頁與活動頁建立流程、月份／日期、錯誤、手機及鍵盤操作, 更新文件並提交。

## 驗證方式

- 使用獨立 SQLite 與 API 做瀏覽器寫入驗證, 不污染日常 Docker 資料。
- 驗證 10/24 預選、跨月份、既有詳情與日期格入口, 活動多天／約戰一天。
- 驗證儲存失敗可重試、儲存成功月曆即時更新、取消焦點返回。
- 檢查桌面與手機版面, 執行既有測試、一般 build 與 GAS 單檔 build。
